# Public-release checklist

- [ ] Target journal and authorship order are agreed for all included papers.
- [ ] Each near-final manuscript was sent to DataMed at least 30 days before journal submission.
- [ ] DataMed/Merative clearance explicitly covers the intended public repository contents.
- [ ] No person-level, claim-level, or licensed MarketScan files are present anywhere in Git history.
- [ ] No unpublished result table, figure, manuscript, or run log is present unless specifically
      cleared for release.
- [ ] All cells in any cleared aggregate output satisfy the disclosure rule, and suppressed values
      cannot be reconstructed by subtraction.
- [ ] Public mortality and CPT lifecycle inputs have complete source citations.
- [ ] Dependency versions and exact run order are documented.
- [ ] CI passes on the release commit.
- [ ] Citation metadata and an approved open-source license are added.
- [ ] Repository visibility is changed from private to public only after the preceding checks pass.
